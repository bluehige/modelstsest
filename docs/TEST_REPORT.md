- Khronos 공식 glTF Validator 실행. 독립 재읽기와 내부 구조 검사를 공식 인증으로 부르지 않는다.

## Blender에서 수행할 인수 확인

1. 사용자 큐브가 있는 기존 씬에서 01_build_city.py 실행 → 원래 씬과 큐브가 남는지 확인.
2. 생성 씬에서 반복 주택의 Mesh 데이터가 공유되는지, Color 속성이 표시되는지 확인.
3. 카메라 Overview / TownSquare / Top 확인 후 F12 렌더.
4. 건물 이동 → 02_export_city.py → 새 Blender 파일에서 GLB 재임포트해 이동이 유지되는지 확인.
5. village 재생성 및 다른 seed 확인. 생성 씬의 기존 수동 수정은 교체되는 것이 명시된 동작이다.
6. 숨겨진 컬렉션 내보내기 거부 및 Object Mode 안내 확인.
